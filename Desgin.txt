请为一个名为 Her 的高端婚恋关系运营平台设计完整前端界面，要求直接输出高保真、可上线级别的 Web UI，视觉必须达到顶级审美、顶级质感、顶级商业产品完成度，不要做成普通 SaaS 模板，也不要做成廉价婚恋 App 风格。

  一、产品定位
  这是一个面向高净值婚恋服务、专业红娘团队、关系运营团队的 Relationship Operations Platform，不是泛社交应用。
  它的核心不是“刷卡匹配”，而是：
  1. 候选人智能检索
  2. 用户画像与偏好沉淀
  3. 资料可信度与风险识别
  4. 双向撮合与关系推进
  5. 聊天协作与辅助建议
  6. 红娘/运营团队的数据化工作台

  二、整体视觉方向
  请采用“高级编辑感 + 奢华信任感 + 数据工作台”的混合视觉语言：
  1. 气质关键词：premium, editorial, intelligent, restrained, trustworthy, modern luxury
  2. 避免廉价相亲站、粉色俗套、社交 App 套版、千篇一律后台模板
  3. 风格上融合：
     - 高级杂志 editorial 排版
     - 精品咨询公司式信任感
     - 顶级数据平台的秩序感与信息密度
  4. 画面要克制、冷静、成熟、昂贵，不要花哨，不要幼态，不要娱乐化

  三、配色要求
  优先使用浅色高级底，不要默认深色模式。
  推荐主色体系：
  - Primary: #0F172A 或 #1C1917
  - Secondary: #334155 或 #44403C
  - Accent / CTA: #CA8A04
  - Background: #F8FAFC 或 #FAFAF9
  - Text: #020617 或 #0C0A09

  整体效果应呈现：
  深海军蓝 / 墨黑 + 香槟金点缀 + 大面积留白 + 细腻灰阶层次
  绝对不要紫色主导，不要廉价粉金，不要互联网默认蓝紫渐变。

  四、字体与排版
  请使用强烈的高级排版系统：
  - 标题字体：Newsreader、Playfair Display、Libre Bodoni、Bodoni Moda 这类有 editorial 气质的 serif
  - 正文字体：Inter、Public Sans、Source Sans 3、Jost 这类干净现代 sans
  - 要形成“高对比标题 + 冷静正文”的组合
  - 标题要有杂志封面感，但不能影响可读性
  - 内容区要有强秩序网格与呼吸感

  五、页面范围
  请直接设计一个完整产品的关键页面，而不是只做 landing page。至少包括以下模块和页面：

  1. 登录页 / 品牌入口页
  - 左侧为品牌宣言与高级视觉
  - 右侧为登录卡片
  - 带有极简但非常精致的背景层次、微妙纹理、柔和渐变、几何切片或光影块面

  2. 总览 Dashboard
  这是整个系统的核心工作台。
  需要包含：
  - 顶部 KPI 区：活跃候选人、待跟进案例、可信资料占比、风险提醒、双向匹配数、聊天推进中案例数
  - 运营趋势图
  - 可信度分层卡片
  - 风险告警卡片
  - 今日待办
  - 最新匹配案例流
  - 最近对话动态
  - 数据卡片需要精致、克制、可点击 drill-down

  3. 候选人搜索页面
  这是高端婚恋运营团队最重要的页面之一。
  需要有：
  - 左侧高级筛选面板
  - 右侧候选人结果区
  - 支持按年龄、城市、学历、身高、婚史、子女情况、职业、收入区间、认证等级、活跃状态、结婚意向等筛选
  - 结果卡片不能像普通招聘网站
  - 每张候选人卡片要有：
    - 头像区
    - 姓名/年龄/城市/职业
    - 标签信息
    - 资料可信度状态
    - 风险提示或安全状态
    - 匹配理由摘要
    - 可展开查看详情
  - 页面要体现“精筛”“甄别”“信号密度高”的感觉

  4. 候选人详情页
  这是一个重点页面，必须做出顶级视觉与信息架构。
  内容包括：
  - 大图头像/资料头图区域
  - 基础档案
  - 教育/职业/城市/婚史/子女/家庭/结婚意向
  - 个人性格与沟通偏好
  - 可信度模块
    - 哪些字段已验证
    - 哪些字段仅用户自填
    - 照片/真人/学历/职业/身份等认证状态
  - 风险信号模块
  - 运营备注时间线
  - 系统匹配理由
  - 推荐对象/互配对象侧边栏
  整体要像“高端客户档案 + 智能决策面板”的结合体。

  5. 撮合案例 / Match Case 页面
  需要展示：
  - 当前案例状态
  - A / B 双方摘要卡片
  - 双向匹配原因
  - 风险与冲突点
  - 红娘推进记录
  - 当前阶段时间线
  - 待处理动作
  - 推荐下一步建议
  这个页面应有强烈的“案件管理 / 关系推进 / 高级运营工作流”感。

  6. 聊天协作页面
  不是普通 IM 聊天窗口，而是“关系协作聊天工作台”。
  需要包含：
  - 中间主聊天流
  - 左侧会话列表
  - 右侧辅助洞察面板
  - 右侧可显示：
    - 用户画像摘要
    - 对话风险提示
    - 建议回复草稿
    - 本轮可提取的偏好线索
    - 红娘备注
  界面气质要更接近高端 concierge 工作台，而不是微信网页版。

  7. 资料可信度 / 风险中心
  需要单独做一个非常强的页面：
  - 展示字段级可信度，而不是简单总分
  - 例如：照片已真人认证、学历已认证、职业未认证、收入为自填
  - 风险信号单独展示，不和推荐分混算
  - 有高风险行为记录、待人工复核、导流风险、资料不符风险等模块
  - 视觉上要专业、冷静、权威

  六、布局与组件要求
  1. 使用宽屏布局，适配桌面优先，同时确保平板和移动端不崩
  2. 侧边导航必须高级，不要通用 admin 模板感
  3. 卡片圆角、阴影、边框要克制精细，不能浮夸
  4. 使用层次分明的数据卡、表格、筛选器、标签、状态徽章、时间线、抽屉、详情面板
  5. 所有状态标签要有统一体系：
     - 已认证
     - 待补充
     - 自填
     - 低风险
     - 需复核
     - 高风险
     - 双向匹配
     - 待跟进
  6. 支持 hover、focus、选中、展开、过滤动画，但动画必须克制、丝滑、专业
  7. 所有可点击卡片、行、标签、按钮都要有明确交互反馈

  七、视觉细节要求
  1. 背景不能是平涂白色，应用细腻渐变、柔和噪点、轻纹理、超淡几何分区来提升高级感
  2. 图表、时间线、统计卡需要极强秩序感
  3. 图标使用简洁线性风格，避免 emoji 和卡通图标
  4. 大量使用留白、分割线、精细字重对比来体现 premium 感
  5. 整体要像“高端私人银行后台 + 精品婚恋顾问平台 + 编辑型视觉系统”的融合

  八、交互原则
  1. 强调可读性、可信度、决策效率
  2. 不要只追求炫技，要兼顾真实商业产品落地
  3. 候选人检索、档案阅读、关系推进必须高效
  4. 风险信息必须醒目但不造成界面惊悚感
  5. 对话和案例页面要强调“辅助判断”和“下一步动作”

  九、技术输出要求
  请直接生成一个完整的现代 Web 前端界面方案，风格统一，组件齐全。
  优先使用：
  - React
  - Next.js 风格组件结构
  - Tailwind CSS
  - 高质量图表占位
  - 高保真 mock data
  - 响应式布局
  - 可直接继续开发的组件化结构

  十、明确禁止
  禁止输出：
  - 普通粉色恋爱 App 风格
  - 低幼插画风
  - Dribbble 式只有 hero 没有产品逻辑的假页面
  - 泛后台模板风
  - 紫色主导的 AI SaaS 套壳风
  - 过度玻璃拟态
  - 花哨渐变和俗气奢华感

  十一、最终目标
  我要的不是一个“还能看”的页面，而是一个真正具备顶级审美、顶级商业感、顶级信任感、顶级信息架构能力的前端系统。
  请直接给出高保真完整设计，不要只给简略线框图。
