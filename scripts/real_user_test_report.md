## 一、测试概述

### 测试目标
模拟真实用户在发现页进行长时间复杂对话，验证：
1. **搜索逻辑**：向量筛选、Agent判断、推荐质量
2. **画像写入逻辑**：会话结束后的画像更新、向量库写入
3. **整体流程**：多轮对话、状态转换、数据一致性

### 测试方法
- 模拟真实用户行为（不确定意图、多话题切换、边缘场景）
- 进行长时间复杂对话（5-10轮）
- 观察和记录问题（只测试不修复）

### 测试范围
覆盖场景：
- **Phase 1**: 模糊意图 + 口语化表达（4个测试场景）
- **Phase 2**: 多意图冲突 + 条件修改（3个测试场景）
- **Phase 3**: Agent幻觉测试（跨轮次引用候选人）
- **Phase 4**: 深层次需求挖掘（3个测试场景）
- **Phase 5**: 极端条件 + 边界场景（3个测试场景）
- **Phase 6**: 画像写入验证（3轮对话透露个人信息）

## 三、根因分析（五问法）

### 问题P0-1：性别过滤失效

```
问题现象：用户说"找个女生"，返回男性候选人（胡睿衡、高子峰、李承远）
├─ 为什么 1: 为什么性别硬约束没有生效？
│   → 检查：criteria_compiler.py是否正确提取性别条件
├─ 为什么 2: 为什么用户说"女生"，Agent没有识别为性别约束？
│   → 检查：Agent意图识别逻辑是否正确提取"女生"→性别=女
├─ 为什么 3: 为什么搜索工具没有应用性别过滤？
│   → 检查：search_matching.py是否正确应用性别硬约束
├─ 为什么 4: 为什么候选人数据中性别字段可能错误？
│   → 检查：数据库中候选人性别字段是否正确
└─ 为什么 5: 【根本原因】性别硬约束提取逻辑失效

根本对策：检查Agent意图识别和criteria_compiler逻辑，确保性别条件正确提取并应用
```

---

### 问题P0-2：候选人切换失效

```
问题现象：用户说"换个候选人"，返回相同候选人ID列表
├─ 为什么 1: 为什么第二轮搜索返回了相同的候选人？
│   → 检查：是否有候选人缓存、多样性筛选是否失效
├─ 为什么 2: 为什么用户说"换个候选人"，Agent没有触发新搜索？
│   → 检查：Agent是否理解"换个候选人"意图
├─ 为什么 3: 为什么搜索逻辑没有排除上一轮的候选人？
│   → 检查：是否有exclude机制排除历史候选人
├─ 为什么 4: 为什么多样性筛选没有生效？
│   → 检查：search_ranking.py多样性排序是否正常工作
└─ 为什么 5: 【根本原因】候选人切换逻辑失效（无多样性筛选、无历史排除机制）

根本对策：检查多样性筛选逻辑、添加历史候选人排除机制
```

## 七、测试结论（更新于 2026-06-23）

### 核心问题总结

当前发现页搜索推荐系统存在**2个P0级问题**（P0-3已关闭），严重影响核心功能：
- ❌ **P0-1: 性别过滤失效**（用户无法找到正确性别候选人）
- ❌ **P0-2: 候选人切换失效**（用户无法看到新候选人）
- ✅ **P0-3: 意图理解失败**（已关闭 - Agent确实理解了意图）

### Agent Native合规性

当前系统**部分违反Agent Native原则**：
- ❌ Agent回复千篇一律（模板化输出）- **待修复**
- ✅ Agent意图识别正常 - **已验证（P0-3关闭）**
- ❌ Agent缺乏自主决策能力 - **待验证**

### 建议优先级

**立即修复**：
- P0-1: 性别过滤失效
- P0-2: 候选人切换失效

**后续修复**：
- P1-1: 向量筛选失效（待验证向量筛选是否真正执行）
- P1-2: 回复模板化（违反Agent Native原则）
- P1-3: 多意图理解失败

**已关闭**：
- ✅ P0-3: 意图理解失败（验证结果：Agent确实理解了意图，测试脚本读取了错误的消息）
