💡 版本管理策略
replace策略（personality_traits, values）
新版本 is_active = true
旧版本 is_active = false（软删除）
原因：性格特质相对稳定，新数据覆盖旧数据
average策略（partner_expectation）
所有版本 is_active = true
搜索时：计算多版本的平均向量
原因：择偶期望可能变化，保留多版本

时间衰减机制（搜索时应用）
后续搜索时生效
📥 输入：搜索相似用户
user_vector: [0.123, 0.456, ...] // 小明的向量 vector_type: "personality_traits" top_k: 50 decay_days: 30 // personality_traits配置
📤 输出：相似用户（带时间衰减）
user_id raw_text 年龄 原始相似度 衰减因子 调整相似度
200 性格内向、喜欢安静 5天 0.95 0.83 0.79
201 性格内向 20天 0.90 0.33 0.30
202 性格温柔 40天 0.85 0.50 0.43
💡 衰减公式
# 时间衰减计算 age_days = (current_time - create_time) / 86400 decay_factor = max(0.5, 1 - age_days / decay_days) adjusted_similarity = similarity * decay_factor # 示例： # age_days = 20, decay_days = 30 # decay_factor = max(0.5, 1 - 20/30) = 0.33 # adjusted_similarity = 0.90 * 0.33 = 0.30
