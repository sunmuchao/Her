## 当前效果

当前系统已经具备：

1. 从候选人记录外部补充照片派生特征
2. 在统一搜索排序中叠加照片分
3. 发现页和推荐系统共用同一套照片排序逻辑
4. 通过正反馈逐步形成用户个体审美偏好

也就是说：

**系统已经不是完全不看照片了。**


## 尚未完全落地的部分

以下部分已经预留结构，但还需要真实数据生产或外部能力接入：

### 1. 照片分析生产任务

当前代码已经有存储结构和排序接入，但还没有在仓库中落地“上传照片后自动产出这些特征”的真实任务。

还需要补：

- 主图选择
- 照片质量评分
- 真实性评分
- 长相描述生成
- `appearance_profile` 向量生成

### 2. 用户负反馈回流

当前已接入最小正反馈：

- `express_interest`

还需要继续补：

- 跳过
- 快速划过
- 详情停留
- 开聊
- 持续聊天

### 3. 向量类型扩展

当前已经有：

- 候选人照片语义文本和偏好聚合骨架

但还没有在现有向量类型配置中正式加入：

- `appearance_profile`
- `appearance_preference`

### 4. 语义筛选

当前还没有把“成熟一点、清爽一点、不要太幼态”这种照片语义接入 `vector_filter`。


## 结论

这次落地完成的是：

**照片排序主链路 + 数据底座 + 正反馈偏好骨架。**

还未完成的是：

**真实照片分析生产任务 + 更完整的行为回流 + 照片语义向量化筛选。**
