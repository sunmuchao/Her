## 🚀 测试执行计划

### Phase 1：手动测试（立即执行）

**目标**：快速验证核心功能和用户体验

**执行步骤**：
1. 按照 `docs/voice-input-test-checklist.md` 执行
2. 记录每个测试项的结果（通过/失败）
3. 记录发现的问题和改进建议
4. 提交测试报告

**预计时间**：30分钟

---

### Phase 2：单元测试（自动化执行）

**目标**：验证Hook功能和API集成

**执行命令**：
```bash
cd frontend/her-app
npm run test:voice  # 或 vitest run use-voice-input.test.ts
```

**预计时间**：5分钟

---

### Phase 3：E2E测试（自动化执行）

**目标**：验证完整流程和微信式体验

**执行命令**：
```bash
cd frontend/her-app
npm run e2e:her  # 或 playwright test tests/e2e/voice-input.spec.ts
```

**预计时间**：10分钟

---

### Phase 4：回归测试（定期执行）

**目标**：确保代码修改后功能仍然正常

**触发条件**：
- 每次修改 `use-voice-input.ts`
- 每次修改 `voice_routes.py`
- 每次修改 `voice-input-button.tsx`
- 每次部署前

**执行内容**：
- 运行所有单元测试
- 运行所有E2E测试
- 执行关键手动测试场景
