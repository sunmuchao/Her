## 1. 稳定靠近型

### 基本信息

- 类型代码：`secure`
- 类型名：`稳定靠近型`
- 趣味名：`稳稳接住派`

### 标签

- 关系里不容易乱猜
- 能靠近也能给空间
- 被在乎时能接得住
- 冲突里不容易先失控

### 极端标签

- `稳定感在线`
  - 关系一旦重要起来，你不太会被一点点回应波动牵着跑，关系里的基础稳定感比较强。
- `靠近自如`
  - 被理解、被接近、被看见这件事，对你来说整体是可承接的。

### 结果总结

- `summary`
  - 你整体更接近低不安、低后撤的状态: 既能靠近，也不太需要靠反复确认或反复设防来稳住关系。

### 详细解释字段

- `relationship_drive`
  - 你通常能同时接受亲近和独立。对你来说，关系更像是可以互相依靠，而不是必须反复确认或反复设防。
- `triggers`
  - 真正会让你不舒服的，往往是长期失去回应、持续不可靠，或者关系里一直讲不清楚、修复不起来。
- `stabilizers`
  - 稳定、可靠、愿意互相支持的关系会让你更自在。你通常不需要很多额外确认，持续在场就够了。
- `common_misread`
  - 你有时会把很多事情先自己消化掉，结果别人未必看得出来，你其实也需要回应和支持。
- `communication_advice`
  - 继续保持这种相对稳定的靠近能力，同时别省略自己的需要。
- `card_tip`
  - 稳稳靠近，也别省略需要。

### 小雅回复骨架

- 开头描述
  - 你更像那种能接受亲近、也能保留独立的人，通常不需要靠反复确认来稳住关系。
- 主体结构
  - 你整体更接近低不安、低后撤的状态。
  - 先记住一句：稳稳靠近，也别省略需要。
  - 更容易被什么触发：长期失去回应、持续不可靠、关系讲不清楚、修复不起来。
  - 更容易稳定下来的条件：稳定、可靠、愿意互相支持。
  - 常见反应偏向：很多事先自己消化，别人未必看得出来你也需要回应。
  - 一句更有用的话：继续保持这种相对稳定的靠近能力，同时别省略自己的需要。

## 2. 高敏确认型

### 基本信息

- 类型代码：`anxious`
- 类型名：`高敏确认型`
- 趣味名：`回应雷达开很满`

### 标签

- 很在意关系有没有持续回应
- 忽冷忽热会很消耗你
- 越喜欢越容易被牵动
- 清楚和稳定会让你安心

### 极端标签

- `回应敏感`
  - 关系一旦重要起来，你会很快从回应变化里感觉到风向不对。
- `靠近自如`
  - 被理解、被接近、被看见这件事，对你来说整体是可承接的。

### 结果总结

- `summary`
  - 你更接近高不安、低后撤的状态: 会明显在意关系有没有持续回应，但通常不会因为亲近本身就先躲开。

### 详细解释字段

- `relationship_drive`
  - 你会更在意关系里的可得性和回应感。越在意一个人，你越希望关系是清楚、稳定、能被确认的。
- `triggers`
  - 你更容易被回应变少、关系变模糊、冲突后迟迟没有修复，或者对方忽近忽远的信号触发。
- `stabilizers`
  - 持续回应、明确表达和冲突后的修复，会明显帮你把注意力从“会不会失去”拉回到关系本身。
- `common_misread`
  - 当线索不够清楚时，你会更倾向先把它理解成关系在降温，而不是普通的忙碌或节奏变化。
- `communication_advice`
  - 把你需要的回应说具体，比如你想知道关系状态、还是想要更稳定的反馈。
- `card_tip`
  - 少一点猜测，多一点确认。

### 小雅回复骨架

- 开头描述
  - 你不是不能独立，你只是会更留意关系里的回应是不是稳定、是不是还在。
- 主体结构
  - 你更接近高不安、低后撤的状态。
  - 先记住一句：少一点猜测，多一点确认。
  - 更容易被什么触发：回应变少、关系模糊、冲突后没有修复、忽近忽远。
  - 更容易稳定下来的条件：持续回应、明确表达、冲突后愿意修复。
  - 常见反应偏向：线索不清楚时，更容易先往关系降温上理解。
  - 一句更有用的话：把你需要的回应说具体。

## 3. 边界后撤型

### 基本信息

- 类型代码：`avoidant`
- 类型名：`边界后撤型`
- 趣味名：`先缓一下派`

### 标签

- 压力一来会先往后退
- 需要空间才能重新靠近
- 不喜欢被情绪追着跑
- 越被逼越容易沉默

### 极端标签

- `稳定感在线`
  - 关系一旦重要起来，你不太会被一点点回应波动牵着跑，关系里的基础稳定感比较强。
- `边界警觉`
  - 一旦关系密度太高、压力太满，你会本能想先把自己往后撤一点。

### 结果总结

- `summary`
  - 你更接近低不安、高后撤的状态: 不一定特别担心被抛下，但在关系太近、太满时会更想先拉开一点。

### 详细解释字段

- `relationship_drive`
  - 你会更在意关系里有没有足够的空间和自主感。比起被快速拉近，你更容易在能保留节奏时放松下来。
- `triggers`
  - 你更容易被推进得太快、被要求立刻袒露很多情绪，或被持续追问和高密度黏连触发。
- `stabilizers`
  - 当对方尊重你的节奏、不把亲近变成压迫，同时又保持稳定可靠时，你会更愿意慢慢靠近。
- `common_misread`
  - 当压力上来时，你可能会过早把需要和情绪收起来。对方看到的常常是距离，不一定看得到你的真实负担。
- `communication_advice`
  - 想退的时候别直接消失，先留一句边界说明，比如“我想缓一下，晚点继续聊”。
- `card_tip`
  - 先讲边界，再谈亲近。

### 小雅回复骨架

- 开头描述
  - 你不是没感觉，你只是会对太快、太满、太没有缓冲的亲近更敏感。
- 主体结构
  - 你更接近低不安、高后撤的状态。
  - 先记住一句：先讲边界，再谈亲近。
  - 更容易被什么触发：被推进太快、被要求立刻袒露情绪、被持续追问、高密度黏连。
  - 更容易稳定下来的条件：被尊重节奏、亲近不等于压迫、对方稳定可靠。
  - 常见反应偏向：压力一上来就先把需要和情绪收起来，外面只看见距离。
  - 一句更有用的话：想退的时候别直接消失，先把边界说出来。

## 4. 拉扯矛盾型

### 基本信息

- 类型代码：`fearful`
- 类型名：`拉扯矛盾型`
- 趣味名：`想靠近也想自保`

### 标签

- 既怕失去也怕太近
- 很在乎但不容易安稳
- 关系里容易反复拉扯
- 需要被理解也需要被放松

### 极端标签

- `回应敏感`
  - 关系一旦重要起来，你会很快从回应变化里感觉到风向不对。
- `边界警觉`
  - 一旦关系密度太高、压力太满，你会本能想先把自己往后撤一点。
- `拉扯感明显`
  - 你既容易被关系牵动，也容易在压力大时先自我保护。

### 结果总结

- `summary`
  - 你更接近高不安、高后撤的状态: 一方面很在意关系，另一方面又容易在压力上来时先自我保护。

### 详细解释字段

- `relationship_drive`
  - 你一方面很在意关系能不能给你确定感，另一方面又会对太快、太满的亲近保持警觉，所以容易同时出现想靠近和想后退。
- `triggers`
  - 你两边都可能被触发: 关系一模糊你会不安，关系一贴太近你又会警觉，所以很容易进入拉扯状态。
- `stabilizers`
  - 既有稳定回应，又给你缓冲空间，不过度逼近的关系，最容易让你一点点放下防御。
- `common_misread`
  - 你可能会一边想确认关系，一边又很快把自己收回去。外面看到的是信号反复，里面其实是又想靠近又怕受伤。
- `communication_advice`
  - 把你需要的回应说具体，比如你想知道关系状态、还是想要更稳定的反馈。 想退的时候别直接消失，先留一句边界说明，比如“我想缓一下，晚点继续聊”。
- `card_tip`
  - 先求稳，再谈靠近。

### 小雅回复骨架

- 开头描述
  - 你会一边想确认关系，一边又会对太近或太不稳同时警觉，所以容易出现靠近和后撤并存。
- 主体结构
  - 你更接近高不安、高后撤的状态。
  - 先记住一句：先求稳，再谈靠近。
  - 更容易被什么触发：关系一模糊会不安，关系一贴太近又会警觉。
  - 更容易稳定下来的条件：既有稳定回应，又有缓冲空间，不过度逼近。
  - 常见反应偏向：一边想确认，一边又很快把自己收回去，外面看到的是反复。
  - 一句更有用的话：把需要的回应说具体，想退的时候也别直接消失。
