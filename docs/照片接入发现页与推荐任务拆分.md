# 照片接入发现页与推荐任务拆分

## 1. 目标

将 [照片接入发现页与推荐完整方案.md](/Users/sunmuchao/Downloads/Her/docs/照片接入发现页与推荐完整方案.md) 拆分成可执行、可排期、可验收的具体任务。

本任务拆分遵循四个原则：

1. 不重写现有发现页、推荐和 `partner_search` 主架构
2. 先补照片派生特征层，再接排序，再做个性化
3. 每一期都可以独立上线并验证收益
4. 发现页和推荐系统共用同一套照片能力底座


## 2. 任务分期

建议拆成 5 期：

1. P0：现状梳理与数据底座
2. P1：候选人照片特征生产
3. P2：搜索排序接入照片分
4. P3：用户动态审美偏好
5. P4：语义筛选、实验和运营化

## 4. P1：候选人照片特征生产

目标：

- 让系统具备“看图并产出可用于匹配的数据”的能力
- 不接用户偏好，先做候选人侧静态特征

### Task P1-1：实现照片分析任务入口

内容：

- 在照片上传、替换、删除后触发照片分析任务
- 保证任务异步执行，不阻塞主流程
- 支持重试和失败状态

涉及模块：

- 照片上传相关后端
- 异步任务调度模块

交付物：

- 照片分析任务触发器

验收标准：

- 照片有更新时会进入 `pending -> processing`


### Task P1-2：实现照片主图选择逻辑

内容：

- 多张照片时选择最适合作为主判定图的一张
- 优先单人、清晰、正脸、非模糊图
- 记录 `primary_photo_id`

交付物：

- 主图选择函数

验收标准：

- 候选人多图情况下，主图选择稳定可复现


### Task P1-3：实现基础照片评分产出

内容：

- 产出 `appearance_score_global`
- 产出 `photo_quality_score`
- 产出 `photo_authenticity_score`

说明：

- 这些分数全部为内部字段
- 不对用户展示

交付物：

- 照片评分任务
- 评分结果写入 `profile_photo_features`

验收标准：

- 给定照片样本，表内可看到对应的 3 类基础分


### Task P1-4：实现长相风格维度分

内容：

- 产出少量稳定维度：
  - `mature_score`
  - `clean_score`
  - `gentle_score`
  - `sunny_score`
  - `stylish_score`

交付物：

- 照片风格维度计算逻辑

验收标准：

- 任意候选人都能产出同一套稳定维度


### Task P1-5：实现口语化长相描述

内容：

- 把长相和照片风格转成一句可向量化的口语描述
- 同时生成 `appearance_tags_json`

示例：

- `看起来干净清爽，偏成熟稳重型`

交付物：

验收标准：

- 描述风格统一、克制、可读

### Task P1-6：为候选人生成照片语义向量

内容：

## 6. P3：用户动态审美偏好

目标：

- 让系统从“平台觉得谁顺眼”
- 升级成“这个用户会喜欢谁”

### Task P3-1：定义照片行为事件

内容：

- 梳理哪些行为可作为审美正负反馈

建议正反馈：

- 点击卡片
- 查看详情
- 停留较久
- 表达感兴趣
- 发起聊天
- 持续聊天

建议负反馈：

- 快速跳过
- 明确拒绝
- 看图后立即离开

交付物：

- 行为事件口径文档

验收标准：

- 每个事件都有明确含义和权重建议

交付物：

验收标准：

交付物：

验收标准：

- 新用户不因为没有历史行为导致照片排序异常

## 9. 每期上线验收建议

### P0 验收

- 表结构和状态机完成
- 照片数据来源清楚

### P1 验收

- 候选人照片可产出分数、描述、向量

### P2 验收

- 发现页和推荐系统都已使用照片排序

### P3 验收

- 用户个体偏好分开始生效
- 同一候选人在不同用户面前排序差异化

### P4 验收

- 可做照片语义筛选
- 可做 A/B 实验
- 指标可观测


## 10. 推荐实施顺序

如果只考虑最快上线，建议顺序如下：

1. 先做 P0
2. 再做 P1
3. 紧接着做 P2
4. P3 在有足够行为数据后上线
5. P4 作为增强项推进

原因：

- P1 + P2 就能解决“系统完全不看照片”的核心问题
- P3 才真正解决“不同用户审美不同”的问题
- P4 属于能力放大器，不是第一优先级


## 11. 一句话总结

本任务拆分的核心思路是：

**先把照片变成稳定可用的派生特征，再把这些特征接进现有统一搜索排序，最后再让用户行为把照片能力个性化。**
