## 3. 当前结果结构

### 3.1 结果卡

结果卡当前只承担“快速结论”功能，不展示大段说明文字。

结果卡内容包括：

- 类型代码
- 雷达图
- 产品化标签
- 极端标签

结果卡不再展示：

- 大段官方解释
- 长篇关系分析
- MBTI 使用边界长文

### 3.2 小雅解读

小雅解读承担“完整解释”功能。

小雅消息由四段组成：

1. `greeting`
2. `identity`
3. `quirk`
4. `suggestion`

其中会使用富文本标记帮助用户抓重点：

- `**加粗**`
- `==高亮==`
- `__下划线__`

## 4. 类型判定规则

类型代码由四个维度分数决定：

- `ei >= 50` 取 `E`，否则取 `I`
- `sn >= 50` 取 `S`，否则取 `N`
- `tf >= 50` 取 `T`，否则取 `F`
- `jp >= 50` 取 `J`，否则取 `P`

这代表“当前更接近哪组偏好”，不是临床诊断，也不是永久标签。

## 5. 四个维度的标准解释

### E / I

- `E / Extraversion`：你更可能通过外部互动获得能量，倾向边交流边形成想法。
- `I / Introversion`：你更可能先在内部整理想法，再决定要不要表达。

关系沟通延伸：

- `E`：在关系里，你通常更愿意把想法说出来，也更需要互动感。
- `I`：在关系里，你通常需要自己的整理空间，安静并不等于冷淡。

### S / N

- `S / Sensing`：你更容易关注事实、细节和已经发生的信息。
- `N / Intuition`：你更容易关注模式、意义和还没发生的可能性。

关系沟通延伸：

- `S`：在关系里，你通常更在意具体表现、稳定兑现和现实安排。
- `N`：在关系里，你通常更在意默契感、趋势判断和未来想象。

### T / F

- `T / Thinking`：你做判断时更可能先看逻辑、公平和标准是否一致。
- `F / Feeling`：你做判断时更可能先看价值、感受和对人的影响。

关系沟通延伸：

- `T`：在关系里，你通常会先分析问题，希望把事情说清楚。
- `F`：在关系里，你通常更在意语气、理解感和彼此是否被照顾到。

### J / P

- `J / Judging`：你更偏好结构、计划和相对确定的推进方式。
- `P / Perceiving`：你更偏好灵活、开放和保留调整空间。

关系沟通延伸：

- `J`：在关系里，你通常更希望节奏清楚、承诺明确、安排可预期。
- `P`：在关系里，你通常更希望保留余地，不想被过早定死。

## 6. 16 型核心摘要

这些摘要用于类型级别的结论说明，是当前 MBTI 结果内容里最稳定的一层。

| 类型 | 核心摘要 |
| --- | --- |
| INTJ | 你通常会先看长期方向、整体结构，还有这件事到底值不值得做。 |
| INTP | 你通常会先想明白原理，确认逻辑顺不顺，再决定要不要接受它。 |
| ENTJ | 你通常很看重目标推进、结构搭建，还有事情能不能高效往前走。 |
| ENTP | 你通常会先被新点子、不同可能性，还有有来有回的观点碰撞吸引。 |
| INFJ | 你通常更会去看事情背后的意义、长期走向，还有人与人之间深一点的理解。 |
| INFP | 你通常更在意自己认不认同、这段关系真不真，还有内心是不是一致。 |
| ENFJ | 你通常很关注关系氛围、别人有没有被照顾到，以及大家能不能往同一个方向走。 |
| ENFP | 你通常会先被新鲜感、可能性和真实情绪打动，人和关系都要有活力。 |
| ISTJ | 你通常更相信责任、秩序，还有把事情稳稳落地这件事本身。 |
| ISFJ | 你通常会默默关注谁需要被照顾、怎么维持稳定，以及实际支持有没有跟上。 |
| ESTJ | 你通常很看重规则清不清楚、分工明不明确，还有效率够不够高。 |
| ESFJ | 你通常会先照顾关系感受，关注合作顺不顺、氛围稳不稳。 |
| ISTP | 你通常更擅长独立处理问题，先看现实情况，再灵活应对。 |
| ISFP | 你通常更在意真实感受、个人价值，还有表达是不是自然不勉强。 |
| ESTP | 你通常更信即时行动和现场反馈，很多判断是边做边调出来的。 |
| ESFP | 你通常会先被当下体验、现场氛围和真实互动带来的乐趣吸引。 |

## 10. 不再使用的旧口径

以下口径不应再作为 MBTI 官方结果正文使用：

- 天生一对
- 需磨合人格
- 自恋操控型
- 冷漠控制型
- 谁更成熟
- 谁天生适合谁
