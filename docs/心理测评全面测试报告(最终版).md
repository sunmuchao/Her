  ```typescript
  'sn': { high: '直觉', low: '感觉' }  // ❌ 完全反了!
  ```
- **正确代码**:
  ```typescript
  'sn': { high: '实感', low: '直觉' }  // ✅ S(实感)是高分,N(直觉)是低分
  ```

**问题分析**:
- ISTP的SN维度得分是70分(>=50,高分)
- 后端判定: 类型代码显示 **S** (实感) ✅
- 前端判定: isHigh=true, 显示 `dimLabel.high`
- **错误**: `dimLabel.high`被定义为"直觉" ❌
- **正确**: 应该是"实感"或"关注现实细节"

## 💡 关键发现

### MBTI维度定义要点

**SN维度的正确理解**:

很多开发者容易混淆SN维度:
- **S(实感/Sensing)**: 关注现实细节、可落地信息、具体数据 → 分数>=50
- **N(直觉/Intuition)**: 关注可能性、趋势、灵魂共鸣 → 分数<50

**常见错误**:
```typescript
// ❌ 错误理解: 认为"直觉"是高分
'sn': { high: '直觉', low: '实感' }

// ✅ 正确理解: S(实感)是高分,N(直觉)是低分
'sn': { high: '实感', low: '直觉' }
```

### 前后端一致性原则

**核心原则**: 前端维度标签必须与后端判定逻辑完全一致

- **判定逻辑**: `>=50` 取第一个字母, `<50` 取第二个字母
- **前端显示**: isHigh=true显示`high`标签, isHigh=false显示`low`标签
- **一致性要求**: 前端`high`标签必须对应后端高分(第一个字母)
