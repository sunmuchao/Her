## 一、测评体系概览

### 1.1 测评设计理念

**核心原则：测评不是"一次性测试"，而是"持续画像"**

```
传统模式：
用户做测试 → 出报告 → 结束

AI Native 模式：
用户做测试 → AI 对话解读 → 画像存储 → 匹配增强 → 聊天应用 → 持续更新
```

**关键设计要点**：

| 设计要点 | 方案 |
|---------|------|
| **UI展示** | 对话中生成卡片UI，不跳转页面 |
| **数据存储** | 写入现有偏好表 `user_personas.self_personality_traits_json` |
| **匹配应用** | 存入数据库后，AI 自主读取判断，不硬编码规则 |
| **触发方式** | AI 发现画像缺失 → 自然引导 → 用户说不知道 → 推荐测评 |

### 1.2 测评清单

| 测评名称 | 测评内容 | 题数 | 完成时间 | 用户价值 |
|---------|---------|------|---------|---------|
| **MBTI 16型人格** | E/I、S/N、T/F、J/P 四个维度 | 20题 | 约5分钟 | 了解性格类型，知道恋爱中会吸引谁、抗拒谁 |
| **依恋风格测验** | 安全型、焦虑型、回避型、恐惧型 | 12题 | 约3分钟 | 了解恋爱中的安全感来源 |
| **价值观拍卖会** | 用10个筹码竞拍20个人生拍品 | 无固定题目 | 约2分钟 | 快速了解三观是否合拍 |
| **大五人格** | 开放性、尽责性、外向性、宜人性、神经质 | 20题 | 约5分钟 | 科学性格画像（心理学界黄金标准） |

## 二、MBTI 16型人格测评

### 2.1 测评概述

**MBTI（Myers-Briggs Type Indicator）** 是最知名的性格测评工具，从四个维度判断性格类型：

| 维度 | 中文名称 | 测什么 | 高分特征 | 低分特征 |
|------|---------|--------|---------|---------|
| **Extraversion (E/I)** | 外向/内向 | 能量来源 | E：热情、健谈、活跃 | I：内向、安静、独处 |
| **Sensing (S/N)** | 实感/直觉 | 信息获取 | S：务实、细节、经验 | N：抽象、创意、想象 |
| **Thinking (T/F)** | 思考/情感 | 决策方式 | T：逻辑、客观、分析 | F：情感、价值、和谐 |
| **Judging (J/P)** | 判断/知觉 | 生活态度 | J：计划、结构、决断 | P：灵活、随性、开放 |

**16型人格组合示例**：
- ENFP：竞选者（热情、创意、自由）
- INFJ：提倡者（理想、洞察、坚定）
- INTJ：建筑师（战略、独立、决断）
- ENFJ：主人公（魅力、同理心、领导）

### 2.2 题目设计特点

**口语化网感表达**：题目贴近恋爱场景，使用网络化语言

**示例题目**：

```
第1题：和刚认识的Crush进行了一场长达6小时的完美约会，分开上地铁后你的真实状态是？

选项：
A. 兴奋到头皮发麻，立刻在闺蜜/兄弟群发长文复盘，顺便发个朋友圈（得分：5，E倾向）
B. 在微信上继续跟Crush黏黏糊糊地聊天：【到家了吗？今天好开心呀】（得分：4，E倾向）
C. 感觉挺好，各回各家，看对方怎么发消息再接话（得分：3）
D. 戴上降噪耳机，开始在手机上玩游戏或刷视频，享受属于自己的时间（得分：2，I倾向）
E. 瞬间闭目养神，感觉今日份的人类社交电量已彻底归零，谁也别戳我（得分：1，I倾向）
```

**计分规则**：
- 每维度5题，共20题
- 每题5个选项，得分1-5分
- 维度得分计算：`(总分 - 5) / 20 * 100`
- 得分≥50则为该维度的第一个字母（如EI维度≥50为E），否则为第二个字母（I）

### 2.3 极端标签机制

**当用户某个维度得分极端时，显示趣味标签**：

## 三、依恋风格测评

### 3.1 测评概述

**依恋理论**（Bowlby 1969, Hazan & Shaver 1987）将人的依恋风格分为四种：

| 类型 | 中文名称 | 特征 | 恋爱表现 |
|------|---------|------|---------|
| **secure** | 安全型 | 情绪稳定，能平衡亲密和独立 | 不黏也不冷，稳如老狗 |
| **anxious** | 焦虑型 | 黏人，需要很多安全感 | 对象回消息慢5分钟已脑补是不是不爱我了 |
| **avoidant** | 回避型 | 冷暴力大师，需要很多空间 | 对象黏太紧觉得窒息要逃跑 |
| **fearful** | 恐惧型 | 矛盾纠结体，既想黏又怕被伤害 | 既想靠近又想逃跑，完全不知道咋办 |

### 3.2 题目设计

**每类型3题，共12题**

**反向计分机制**：
- 焦虑、回避、恐惧维度是反向计分
- 选A（稳定/不焦虑）得5分 → 转换后得低分（20分）
- 选E（极度焦虑）得1分 → 转换后得高分（80分）

**示例题目**：

```
第4题：对象回消息慢了2小时，你啥状态？

选项：
A. 稳如老狗，TA可能在忙，我也有自己的事（得分：5 → 低焦虑）
B. 有点好奇TA在干嘛，发个表情包戳一下（得分：4）
C. 发了好几条消息问TA在干嘛，有点急（得分：3）
D. 已脑补TA是不是遇到更好的人了，是不是不爱我了（得分：2 → 高焦虑）
E. 连分手后的财产分配都想好了，TA完了（得分：1 → 极度焦虑）
```

### 3.4 匹配规则

**核心匹配规则**：

| 组合 | 匹配度 | 原因 |
|------|-------|------|
| **安全型 + 任何类型** | 高分 | 安全型能适应任何类型 |
| **焦虑型 + 回避型** | 低分 | 追逐-逃跑恶性循环 |
| **恐惧型 + 任何** | 中低分 | 需要理解TA的矛盾 |
| **焦虑型 + 焦虑型** | 中分 | 可能过度依赖 |
| **回避型 + 回避型** | 低分 | 可能互相疏离 |

## 五、价值观拍卖会

### 5.1 测评概述

**一句话定义**：价值观拍卖会 = 用10个筹码"竞拍"你最看重的人生特质，在取舍中暴露真实价值排序。

**核心设计原则**：

1. **用户看到的是"拍品"，不是"价值观标签"**
   - 不直接展示：诚实、健康、自由、善良
   - 展示：无论发生什么都永远不离不弃的灵魂伴侣

2. **前台玩拍品，后台算价值观**
   - 前端展示拍品卡，后端保留隐藏价值映射

3. **拍品之间必须有冲突**
   - 百亿上市公司 vs 内心平静
   - 灵魂伴侣 vs 无需讨好任何人

### 5.5 单人玩法流程

**五幕设计**：

```
第一幕：入场
├─ 标题：今晚，你只能拍下 10 枚筹码 worth 的人生
├─ 提示：20 件拍品，10 枚筹码，不可能全都要
└─ CTA：进入拍卖场

第二幕：首轮抢拍
├─ 20 张拍品卡按 4 大展厅分区
├─ 用户点开拍品卡后，可以：出 1 枚、长按连投、拖拽筹码
└─ 每次投出时做轻反馈：筹码飞向拍品、余额减1、亮度上升

第三幕：取舍加压
├─ 剩余 5 枚时：轻提醒
├─ 剩余 3 枚时：强化取舍提示
└─ 剩余 1 枚时：进入封盘前紧张状态

第四幕：封盘确认
├─ 展示当前最高的 3 个拍品
├─ 展示一票未出的拍品
└─ 文案：这就是你今晚真正舍不得放掉的人生

第五幕：揭晓与解读
├─ 第3名拍品翻牌
├─ 第2名拍品翻牌
├─ 第1名压轴拍品翻牌
└─ 显示：主倾向总结、被你放弃的世界、相处建议
```

### 5.6 双人玩法（盲拍对照）

**核心定义**：双人版不叫"双人答题"，而叫"盲拍对照"

**流程**：

```
第一步：发起邀请
├─ 文案：来一场盲拍吧，看看你们抢的是不是同一种人生
└─ 必须明确：双方都封盘后才会同时揭晓

第二步：同时入场
├─ 两个人进入同一场 session
├─ 彼此完全不可见
└─ 提示：这是秘密出价，封盘前没人知道你抢了什么

第三步：各自拍卖
└─ 交互与单人一致

第四步：等待对方封盘
├─ 文案：你的拍品已锁定，对方仍在出价中
└─ 封盘后将同时揭晓：共鸣点、分歧点、最危险的冲突

第五步：同时揭晓
├─ 先揭晓你拍下了什么
├─ 再揭晓TA拍下了什么
├─ 展示你们共同抢下的东西
└─ 高亮你最看重的，TA几乎没出价
```

### 5.7 匹配分析

**生成双人三观匹配分析**：

```typescript
interface MatchAnalysis {
  match_type: "高度契合" | "中等契合" | "需要磨合" | "一般契合";
  common_lots: string[];          // 共鸣拍品（双方都高投）
  common_hidden_values: HiddenValue[]; // 共鸣的隐藏价值
  misalignments: Misalignment[];  // 错位拍品（一方高投、一方低投）
  conflicts: Conflict[];          // 冲突拍品（一方最看重、另一方几乎0投）
}
```

**匹配类型判断规则**：

- 共鸣拍品 ≥ 2 且冲突 = 0 → "高度契合"
- 共鸣拍品 ≥ 1 且冲突 ≤ 1 → "中等契合"
- 冲突 ≥ 2 → "需要磨合"
- 其他 → "一般契合"
