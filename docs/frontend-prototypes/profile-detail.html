Page Direction

详情页的职责不是堆字段，而是承接红娘在发现页里的判断。

用户从发现页点进来时，最重要的不是看到更长的资料列表，而是先理解“红娘为什么把这个人给我、这个人到底哪里可信、哪里还要我自己确认”。所以这页先给判断，再给字段，最后给聊天建议。

先说为什么出现 用户要先知道“为什么这人值得看”，而不是一上来被资料细节淹没。
可信度必须拆开 已核验、自填、待确认、风险提醒分开写，避免用户误以为整份资料都被平台背书。
详情页要反哺聊天 最后必须给出“建议先聊什么”，这样用户从详情页回到聊天页才有下一步动作。
