# 1. 短信验证码登录页

### 页面名称 & 功能概述
用于手机号登录，分两步完成验证码发送与校验，并根据 `flow.scenario` 自动区分新用户与老用户入口。

### 页面布局架构
- 中央居中单卡片布局
- 卡片上半区为品牌与一句价值主张
- 卡片主体为手机号输入、验证码输入、发送按钮、验证按钮
- 卡片底部展示验证码发送状态、倒计时、下一步去向提示

### 核心 UI 组件清单
- 手机号输入框
- 验证码输入框，6 位分格输入
- 发送验证码按钮
- 倒计时按钮状态
- 提交登录主按钮
- 错误提示 Alert
- 流程提示卡片

### 数据字段映射
- `phone` / `mobile`：手机号输入框，必须做中国大陆手机号格式校验
- `code` / `otp`：6 位验证码输入框
- `delivery.masked_phone`：发送成功后以弱提示文案展示
- `delivery.expires_in_seconds`：倒计时文案
- `delivery.resend_in_seconds`：禁用发送按钮并显示秒数
- `delivery.provider`：隐藏在调试信息或小字说明中
- `flow.scenario`：用小标签显示“新用户”或“老用户”
- `flow.next_path`：登录成功后跳转路径，用说明文字展示

### 交互与逻辑流
- 点击“发送验证码”后，按钮进入 Loading，成功后切换为倒计时态
- 输入不合法手机号时，输入框红框，底部显示中文错误
- 点击“登录/验证”后，按钮 Loading；成功则根据 `next_path` 跳转
- `sms_cooldown`、`code_expired`、`code_mismatch`、`code_locked` 需显示明确错误提示
