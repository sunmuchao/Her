# 7. 推荐卡片中心

### 页面名称 & 功能概述
面向终端用户或客服查看已投递的站内推荐卡片，并支持已读操作。

### 页面布局架构
- 顶部筛选栏
- 中部瀑布流或卡片列表
- 右侧为卡片详情预览

### 核心 UI 组件清单
- 卡片筛选器
- 推荐卡片列表
- 已读/未读切换
- 卡片详情面板

### 数据字段映射
- `card_id`：卡片 ID
- `requester_id`：持卡用户 ID
- `card_status`：未读/已读 Tag
- `delivered_at`：投递时间
- `read_at`：已读时间
- `payload`：卡片内容主体，包含标题、候选人信息、摘要文案、跳转动作

### 交互与逻辑流
- 卡片默认按 `delivered_at` 倒序
- 点击卡片后右侧打开详情并自动触发“标记已读”
- 批量勾选卡片可统一标记已读
