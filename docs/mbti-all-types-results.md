【INTJ】策略家 - 深海理智怪
================================================================================

一、基本信息
----------------------------------------
文艺昵称: 深海理智怪
网感昵称: 紫老头
认知功能栈: Ni-Te-Fi-Se

二、维度分数
----------------------------------------
外向/内向: 30分 - 你更偏内向，通常喜欢安静和深入交流。
实感/直觉: 30分 - 你更偏直觉，习惯先看趋势和可能性。

判断/知觉: 70分 - 你更偏计划和确定性，喜欢把事情安排清楚。

三、维度总结（专业表述）
----------------------------------------
1. 相处时，你更习惯 先自己消化
2. 看人和看关系时，你更看重 思维的共鸣和未来的可能性
3. 遇到分歧时，你更容易站在 逻辑和标准 这边
4. 推进关系时，你更偏 先对齐节奏

四、性格标签
----------------------------------------
1. 表面不动如山内心掏出扣分表
2. 冲突时倾向先分析问题再处理情绪
3. 浪漫绝缘体（但成熟的能学会表达情感）
4. 吵架偏好复盘逻辑问题
5. 爱是解决方案不是多喝热水

五、恋爱说明书
----------------------------------------
优势: 长期主义护航者，爱从来不是嘴上的多喝热水而是解决方案
坑点: 浪漫绝缘体，你想听一句我错了TA坚持要复盘逻辑问题

成长路径: 第四功能Fi（情感价值）发育后，能从逻辑输出转向情感表达

最佳匹配:
  - ENFP（快乐小狗）
  - 为啥配：TA能用没心没肺的快乐强行照亮你的深海世界
  - 日常场景：你默默解决实际问题，TA强行拽你出门体验生活

需磨合匹配:
  - ISFP（氛围感受器）
  - 为啥可能合拍也可能虐心：你俩是'内向版的TA'和'外向版的你'——一个深挖一个广撒，刚好互补
  - 成熟的合拍场景：你学会情感表达+接住TA的感性，TA学会逻辑沟通+欣赏你的方案，你们能互补

六、成长状态（功能发育阶段）
----------------------------------------

GROWING - 冷漠控制型:
  - 用逻辑分析逃避情感表达
  - 扣分表式恋爱：问题积累到阈值直接分手
  - 完全忽视对方情感需求

LEARNING - 觉察中学习型:
  - 能觉察对方情绪但还不太能表达情感
  - 开始学习先抱再分析
  - 懂得解决问题也需要情感表达

BALANCED - 情智双修型:
  - 能逻辑分析+能情感觉察（第四功能Fi已发育）
  - 先抱再聊问题，解决问题也接情绪
  - 用方案表达爱也能说'我在呢'
