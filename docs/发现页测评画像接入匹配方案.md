# 发现页测评画像接入匹配方案

> 最新说明：这份文档保留“为什么要接、排序公式怎么想”的分析内容；  
> 真正用于执行的主落地稿，已统一到 [发现页测评画像接入方案_AI自主判断版](./发现页测评画像接入方案_AI自主判断版.md)。

> 整理日期：2026-06-05
> 适用范围：发现页推荐链路、Discovery AI 分析链路、候选卡解释层
> 核心问题：`self_personality_traits_json` 已写入，但当前发现页匹配没有真正消费

## 1. 结论先说

当前系统已经做到：

1. 用户完成 MBTI、依恋风格、大五人格、爱情三元论、价值观拍卖后，结果会写入 `user_personas.self_personality_traits_json`
2. 完整结果会写入 `assessment_results`，用于测评结果存档与回溯，不作为发现页匹配主读取源

但当前发现页还没有真正用上这份画像。

问题不在于 AI 不理解 MBTI 或依恋风格，而在于：

1. 搜索排序链路没有把这份数据接进去
2. AI 上下文没有直接拿到 `self_personality_traits_json` 中的核心结构化测评画像
3. 前端候选卡也没有展示“测评为什么更合拍”

## 2. 方案目标

把发现页从：

- “基础资料筛选 + AI 包装话术”

升级成：

- “基础资料筛选 + 保守测评加权 + AI 基于核心结构化测评画像做匹配解释”

目标分 3 层：

1. 排序层有限使用测评数据
2. AI 层直接读取核心结构化测评画像做判断
3. 前端层明确展示测评合拍原因

## 3. 核心原则

### 3.1 不把测评结果先翻译成口语人格标签

不建议走这种路径：

- `INFP` -> “重理解感、需要空间、敏感”
- `secure` -> “稳定靠近、不容易失控”

原因：

1. `INFP`、依恋类型、大五分数本身就是高信息密度结果
2. 先做口语翻译会丢信息
3. 会引入产品自己的解释偏差
4. AI 本来就理解这些结构化人格结果，没有必要先喂缩水版

结论：

- 核心结构化测评画像直接保留
- 核心结构化测评画像直接喂给 AI

### 3.2 测评结果不直接作为硬筛条件

不能把测评结果直接变成：

- 必须匹配
- 必须排除

原因：

1. 心理测评更适合做倾向判断，不适合做硬门槛
2. 直接硬筛会显著缩小候选池
3. 容易制造伪精确

结论：

- 基础资料继续硬筛
- 测评结果只做软排序和 AI 解释

### 3.3 排序层和 AI 层分工不同

排序层：

- 只做有限、可控、可回溯的加权
- 不做开放式人格推理

AI 层：

- 直接读取核心结构化测评画像
- 结合候选人资料判断适配性
- 候选人没有同类测评时，也可以根据其他资料判断

**关键设计原则**：

1. **只包含原始数据**：用户测评结果、候选人测评结果（如有）、候选人基础资料
2. **不预计算软约束结论**：不包含 `compatibility`、`strengths`、`risks`、`reasons` 等预判断字段
3. **包含时效性信息**：每个测评结果包含 `completed_at` 和 `days_since_completion`，用于判断测评是否过期

**为什么不在这里预计算 compatibility**：

| 预计算做法（错误） | 原始数据做法（正确） |
|---|---|
| 排序层提前算好 `strengths = [“价值观接近”]` | AI 自己看原始数据，自己下结论 |
| AI 只能照着预计算结论说 | AI 根据具体场景灵活表达 |
| 所有用户看到的理由都一样 | 不同用户、不同场景，AI 有不同表达 |
| 算法写错，AI 没机会纠正 | AI 可以根据上下文调整判断 |

**职责分工**：

```
personality_match_context（只提供原始数据）
                ↓
        ┌───────┴───────┐
        ↓               ↓
   排序层读取          AI 读取
   原始测评数据        原始测评数据 + 候选人资料
        ↓               ↓
   自己计算分数        自己判断适配性
   （只用于排序）      自己生成 strengths/risks/reasons
```

## 6. 候选人侧输入策略

候选人侧不要强行预判成某个 MBTI。

应分两层：

### 6.1 候选人有真实测评

直接提供：

- 候选人的 `self_personality_traits_json`

### 6.2 候选人没有真实测评

直接提供候选人的其他资料给 AI：

- 基础资料
- 自述
- 标签
- 婚恋目标
- 生活方式
- 公开价值观描述

让 AI 做这种判断：

- 用户是 `INFP`
- 候选人虽然没写 MBTI
- 但从资料看，这个人是否更适合 `INFP`

也就是说：

- 有测评，优先用测评
- 没测评，AI 根据资料推断
- 但不要伪造候选人的测评结果

## 7. 排序层改造

### 7.1 硬筛继续保留

继续保留现有硬筛：

- 城市
- 年龄
- 婚恋目标
- 基础择偶要求

### 7.2 排序层只做保守加权

排序层不适合依赖 AI 的自由发挥，否则：

- 不稳定
- 不可回溯
- 难以灰度

所以建议新增：

- `personality_fit_score`

但它只基于明确结构化测评结果做有限加权，**且有明确的计算公式**。

> ⚠️ **注意**：当前公式设计存在部分问题，详见 [7.4 公式设计问题分析](#74-公式设计问题分析)

#### 7.2.1 各子分计算公式

**values_fit_score**（双方都有价值观测评时才计算）：

> 💡 **改进建议**：当前公式基于重叠率，有心理学依据但过于简化。
> 建议：增加顺序权重 + 冲突检测。

```python
# 价值观相似度：基于 top_values 重叠率（基础版）
def calc_values_fit_score(user_values, candidate_values):
    if not user_values or not candidate_values:
        return None  # 不计算，不参与排序

    user_set = set(user_values["top_values"])
    candidate_set = set(candidate_values["top_values"])

    overlap_count = len(user_set & candidate_set)
    max_possible = min(len(user_set), len(candidate_set))

    return overlap_count / max_possible if max_possible > 0 else 0.0

# 价值观相似度：改进版（增加顺序权重 + 冲突检测）
def calc_values_fit_score_v2(user_values, candidate_values):
    """
    改进版价值观匹配公式

    改进点：
    1. 考虑价值观选择的顺序（排名第一权重更高）
    2. 检测价值观冲突（某些价值观本身就对立）

    参考：
    - Byrne (1971) 相似性-吸引理论：价值观相似性会增加人际吸引
    - Huston & Levinger (1978)：价值观相似是长期关系稳定性的预测因子
    """
    if not user_values or not candidate_values:
        return None

    user_list = user_values["top_values"]  # 按重要性排序的列表
    candidate_list = candidate_values["top_values"]

    # 1. 基础重叠分
    user_set = set(user_list)
    candidate_set = set(candidate_list)
    overlap = user_set & candidate_set

    if not overlap:
        return 0.0

    # 2. 顺序权重：排名越靠前，权重越高
    # 排名第1的价值观权重为3，第2权重为2，第3权重为1
    def get_position_weight(value, value_list):
        if value in value_list:
            position = value_list.index(value) + 1  # 排名从1开始
            return max(3 - position + 1, 1)  # 权重：第1=3, 第2=2, 第3=1
        return 0

    weighted_overlap = 0
    for v in overlap:
        user_weight = get_position_weight(v, user_list)
        candidate_weight = get_position_weight(v, candidate_list)
        # 双方都很重视的价值观，重叠更有意义
        weighted_overlap += (user_weight + candidate_weight) / 2

    # 最大可能权重：假设双方排名完全一致
    max_weight = sum(range(1, min(len(user_list), len(candidate_list)) + 1)) * 2
    base_score = weighted_overlap / max_weight if max_weight > 0 else 0

    # 3. 冲突检测：某些价值观本身对立
    # 定义价值观冲突对（可根据测评设计调整）
    conflict_pairs = [
        ("完全自由的生活", "稳定可预期的日子"),
        ("冒险和挑战", "安稳平淡"),
        # ... 其他冲突对，需要根据实际测评选项定义
    ]

    conflict_penalty = 0
    for pair in conflict_pairs:
        if (pair[0] in user_set and pair[1] in candidate_set) or \
           (pair[1] in user_set and pair[0] in candidate_set):
            conflict_penalty += 0.1  # 每个冲突扣 0.1

    # 最终分数 = 基础分 - 冲突扣分
    final_score = max(0, base_score - conflict_penalty)

    return final_score
```

**权威依据**：
- Byrne, D. (1971). *The Attraction Paradigm*. Academic Press.（相似性-吸引理论）
- Huston, T. L., & Levinger, G. (1978). Interpersonal attraction and relationships. *Annual Review of Psychology*, 29, 115-156.（价值观相似与关系稳定性）

**attachment_fit_score**（双方都有依恋测评时才计算）：

> ⚠️ **重要问题**：以下原公式有逻辑错误，不建议直接使用。
> 问题分析详见 [7.4.1 依恋风格公式问题](#741-依恋风格公式问题)。

**原公式（有问题）**：

```python
# ❌ 问题：差值越小 = 分越高，但这会导致"焦虑型+回避型"得到最高分
# 这个组合在心理学上是最不稳定的"追逐-逃避"模式
def calc_attachment_fit_score(user_attachment, candidate_attachment):
    if not user_attachment or not candidate_attachment:
        return None

    # 差值越小，匹配度越高
    anxiety_diff = abs(user_attachment["anxiety"] - candidate_attachment["anxiety"])
    avoidance_diff = abs(user_attachment["avoidance"] - candidate_attachment["avoidance"])

    # 转换为 0-1 分数：差值越小分数越高
    avg_diff = (anxiety_diff + avoidance_diff) / 2
    return 1.0 - avg_diff
```

**修复后的公式（推荐使用）**：

```python
# ✅ 修复：基于依恋理论的风险分级模型
# 参考：Mikulincer & Shaver (2016) 《Attachment in Adulthood》
def calc_attachment_fit_score(user_attachment, candidate_attachment):
    if not user_attachment or not candidate_attachment:
        return None

    u_anx = user_attachment["anxiety"]
    u_avo = user_attachment["avoidance"]
    c_anx = candidate_attachment["anxiety"]
    c_avo = candidate_attachment["avoidance"]

    # 1. 双方都安全型：高分（最稳定组合）
    # 安全型定义：焦虑度 < 0.3 且 回避度 < 0.3
    if u_anx < 0.3 and u_avo < 0.3 and c_anx < 0.3 and c_avo < 0.3:
        return 0.9

    # 2. 一方安全型 + 另一方非极端：中等分
    # 安全型可以稳定非极端的伴侣
    if (u_anx < 0.3 and u_avo < 0.3) or (c_anx < 0.3 and c_avo < 0.3):
        if max(u_anx, u_avo, c_anx, c_avo) < 0.7:
            return 0.6

    # 3. 焦虑型 + 回避型：低分（追逐-逃避模式）
    # 这是最不稳定的组合，不应给高分
    if u_anx > 0.5 and c_avo > 0.5:  # 用户焦虑 + 候选人回避
        return 0.2  # 用户会"追"，候选人会"逃"
    if c_anx > 0.5 and u_avo > 0.5:  # 候选人焦虑 + 用户回避
        return 0.2

    # 4. 双方相似的非安全型：中等分
    # 相似的焦虑倾向或相似的回避倾向，有一定稳定性
    if abs(u_anx - c_anx) < 0.2 and abs(u_avo - c_avo) < 0.2:
        return 0.5

    # 5. 其他组合
    return 0.4
```

**依恋风格分类定义**：

| 类型 | anxiety | avoidance | 特征 |
|------|---------|-----------|------|
| 安全型 | < 0.3 | < 0.3 | 稳定靠近，不易失控 |
| 焦虑型 | > 0.5 | < 0.3 | 需要确认感，容易"追" |
| 回避型 | < 0.3 | > 0.5 | 害怕靠近，容易"逃" |
| 恐惧型 | > 0.5 | > 0.5 | 既想靠近又害怕靠近 |

**权威依据**：
- Mikulincer, M., & Shaver, P. R. (2016). *Attachment in Adulthood: Structure, Dynamics, and Change*. Guilford Press.（依恋研究最权威综述）
- Collins, N. L., & Read, N. W. (1990). Adult attachment, working models, and relationship quality. *Journal of Personality and Social Psychology*, 58(4), 644-663.

**temperament_fit_score**（双方都有 MBTI 或大五时才计算）：

> 💡 **改进建议**：大五人格不同维度对关系的影响不同，应使用差异化权重。
> 参考：Luo & Klohnen (2005) 的实证研究发现。

```python
# 气质匹配：基于 MBTI 维度差值 或 大五人格维度差值（推荐）
def calc_temperament_fit_score(user_mbti, candidate_mbti, user_big_five, candidate_big_five):
    # 优先用大五人格（更科学，有实证研究支持）
    if user_big_five and candidate_big_five:
        return calc_big_five_fit_score(user_big_five, candidate_big_five)

    # 其次用 MBTI（民间测评，稳定性存疑，但可作为补充）
    if user_mbti and candidate_mbti:
        return calc_mbti_fit_score(user_mbti, candidate_mbti)

    return None  # 都没有，不计算

def calc_big_five_fit_score(user_big_five, candidate_big_five):
    """
    基于 Luo & Klohnen (2005) 研究的加权模型
    参考：Luo, S., & Klohnen, E. C. (2005). Assortative mating and marital quality in newlyweds.
    Journal of Personality and Social Psychology, 88(2), 304-326.

    核心发现：
    - 神经质差异对关系稳定性影响最大（权重最高）
    - 外向性差异影响最小（可以互补）
    - 其他维度相似性通常优于互补性
    """
    u = user_big_five["scores"]
    c = candidate_big_five["scores"]

    # 不同维度的权重不同（基于实证研究）
    weights = {
        "neuroticism": 0.30,    # 神经质差异影响最大，权重最高
        "agreeableness": 0.20,  # 宜人性差异影响较大
        "conscientiousness": 0.20,  # 尽责性差异影响较大
        "openness": 0.15,       # 开放性差异影响中等
        "extraversion": 0.15    # 外向性差异影响最小（可以互补）
    }

    total_diff = 0
    for dim, weight in weights.items():
        diff = abs(u[dim] - c[dim]) / 100
        total_diff += diff * weight

    return 1.0 - total_diff

def calc_mbti_fit_score(user_mbti, candidate_mbti):
    """
    MBTI 民间配对建议（非严格科学依据）
    注意：MBTI 在学术界有争议，信效度不如大五人格
    参考：Pittenger (2005) 的批评性综述
    """
    user_scores = user_mbti["scores"]
    candidate_scores = candidate_mbti["scores"]

    # 计算四个维度差值（权重相同，因为没有明确实证依据）
    diffs = [
        abs(user_scores["ei"] - candidate_scores["ei"]) / 100,
        abs(user_scores["sn"] - candidate_scores["sn"]) / 100,
        abs(user_scores["tf"] - candidate_scores["tf"]) / 100,
        abs(user_scores["jp"] - candidate_scores["jp"]) / 100
    ]

    avg_diff = sum(diffs) / 4
    return 1.0 - avg_diff
```

**权威依据**：

#### 7.2.2 总分合并公式

```python
def calc_personality_fit_score(values_fit, attachment_fit, temperament_fit):
    """
    合并子分为总分
    只计算双方都有对应测评的子分
    缺失的子分不参与计算（不是 0 分，而是不纳入权重）
    """
    available_scores = []

    if values_fit is not None:
        available_scores.append(("values", values_fit, 0.4))  # 价值观权重最高
    if attachment_fit is not None:
        available_scores.append(("attachment", attachment_fit, 0.3))
    if temperament_fit is not None:
        available_scores.append(("temperament", temperament_fit, 0.3))

    if not available_scores:
        return None  # 没有任何子分可计算

    # 重新分配权重，保证总分权重为 1
    total_weight = sum(w for _, _, w in available_scores)
    weighted_sum = sum(score * (weight / total_weight) for _, score, weight in available_scores)

    return weighted_sum
```

#### 7.2.4 测评时效性权重

> 💡 **改进建议**：不同测评类型的稳定性不同，应使用差异化有效期。
> 参考：心理学重测信度研究。

```python
# 原版：统一时效性阈值（不区分测评类型）
# 问题：大五人格比价值观更稳定，不应使用相同阈值
def get_recency_weight(days_since_completion):
    if days_since_completion > 365:
        return 0.0  # 过期，不参与
    elif days_since_completion > 180:
        return 0.25
    elif days_since_completion > 90:
        return 0.5
    else:
        return 1.0  # 新鲜，全额参与

# 改进版：差异化时效性阈值（区分测评类型）
def get_recency_weight(assessment_type, days_since_completion):
    """
    基于心理学研究的差异化有效期

    心理学依据：
    - 大五人格：10年稳定性 r≈0.7-0.8（Costa & McCrae, 1992）
    - MBTI：5年约50%会变（Pittenger, 2005）
    - 依恋风格：2年稳定性 r≈0.5-0.6（Fraley, 2002）
    - 价值观：会随生活事件变化，稳定性较低（Schwartz, 2005）

    建议有效期：
    - 大五人格：1-2年有效
    - MBTI：6-12月有效（民间测评，稳定性存疑）
    - 依恋风格：1年有效（会随关系经历变化）
    - 价值观：6月有效（最易受生活事件影响）
    """
    thresholds = {
        "big_five": {
            "fresh": 365,    # 1年内全额参与
            "decay": 730,    # 1-2年权重减半
            "expire": 1095   # 3年后过期
        },
        "mbti": {
            "fresh": 180,    # 半年内全额参与
            "decay": 365,    # 半年-1年权重减半
            "expire": 730    # 2年后过期
        },
        "attachment": {
            "fresh": 365,    # 1年内全额参与
            "decay": 730,    # 1-2年权重减半
            "expire": 1095   # 3年后过期
        },
        "sternberg": {
            "fresh": 180,    # 半年内全额参与
            "decay": 365,    # 半年-1年权重减半
            "expire": 730    # 2年后过期
        },
        "values": {
            "fresh": 90,     # 3个月内全额参与
            "decay": 180,    # 3-6月权重减半
            "expire": 365    # 1年后过期
        }
    }

    t = thresholds.get(assessment_type)
    if not t:
        # 默认阈值（保守处理）
        t = {"fresh": 90, "decay": 180, "expire": 365}

    if days_since_completion > t["expire"]:
        return 0.0  # 过期
    elif days_since_completion > t["decay"]:
        return 0.25  # 权重大幅衰减
    elif days_since_completion > t["fresh"]:
        return 0.5   # 权重减半
    else:
        return 1.0   # 新鲜，全额参与

# 计算子分时乘以时效性权重（改进版）
def calc_weighted_values_fit_score(user_values, candidate_values):
    base_score = calc_values_fit_score_v2(user_values, candidate_values)
    if base_score is None:
        return None

    # 使用用户测评的时效性
    recency_weight = get_recency_weight("values", user_values["days_since_completion"])

    return base_score * recency_weight
```

### 7.4 公式设计问题分析

> 📌 **本章节总结了公式设计中发现的问题及改进建议，便于后续评审和迭代。**

#### 7.4.1 问题总结表

| 方面 | 原设计问题 | 严重程度 | 改进方案 | 权威依据 |
|------|-----------|---------|---------|---------|
| **价值观匹配** | 重叠率过于简化，未考虑顺序和冲突 | 中 | 增加顺序权重 + 冲突检测 | Byrne (1971), Huston & Levinger (1978) |
| **依恋风格匹配** | ❌ 差值公式违背核心理论，会给"焦虑+回避"打最高分 | **高** | 改用风险分级模型 | Mikulincer & Shaver (2016) |
| **气质匹配** | 大五人格维度权重相同，未区分影响差异 | 中 | 神经质权重最高，外向性最低 | Luo & Klohnen (2005) |
| **权重比例** | 0.75:0.25 无明确依据 | 低 | 作为灰度起点可接受，后续根据数据调整 | 行业实践参考 |
| **时效性** | 统一阈值，未区分测评稳定性差异 | 中 | 大五人格有效期更长，价值观更短 | Costa & McCrae (1992), Pittenger (2005) |

#### 7.4.2 依恋风格公式问题详解

**原公式的问题**：

```python
# 原公式：差值越小 = 分越高
avg_diff = (anxiety_diff + avoidance_diff) / 2
return 1.0 - avg_diff
```

**问题示例**：

```
场景：用户焦虑型（anxiety=0.9） + 候选人回避型（avoidance=0.9）

原公式计算：
- anxiety_diff = |0.9 - 0.9| = 0
- avoidance_diff = |0.9 - 0.9| = 0
- avg_diff = 0
- 匹配分 = 1.0 - 0 = 1.0（最高分！）

心理学事实：
- 焦虑型需要确认感，会"追"
- 回避型害怕靠近，会"逃"
- 形成"追逐-逃避"循环，是最不稳定组合
- 应给低分而非最高分
```

**为什么原公式会出错**：

原公式假设"维度越相似越好"，但依恋风格不是简单的相似匹配：
- 安全型 + 安全型 = 稳定（相似确实好）
- 焦虑型 + 回避型 = 不稳定（相似维度但组合有毒）
- 安全型 + 焦虑型 = 安全型可以稳定对方（不相似但可行）

**修复思路**：

不使用简单的差值公式，而是基于依恋理论的风险分级：
1. 双方都安全型 → 高分（最稳定）
2. 一方安全型 + 另一方非极端 → 中等分（安全型可以稳定）
3. 焦虑型 + 回避型 → 低分（追逐-逃避模式）
4. 双方相似的非安全型 → 中等分（有一定稳定性）

#### 7.4.3 改进优先级建议

1. **P0（必须改）**：依恋风格匹配公式
   - 原公式会给最不稳定组合打最高分
   - 影响匹配质量和用户体验
   - 有明确的心理学理论依据支持修复方案

2. **P1（强烈建议）**：大五人格维度权重
   - 有明确的实证研究支持差异化权重
   - 神经质差异对关系影响最大，应提高权重
   - 外向性可以互补，应降低权重

3. **P2（建议优化）**：价值观冲突检测
   - 实践层面必要（某些价值观本身对立）
   - 需要根据实际测评选项定义冲突对

4. **P3（可后续迭代）**：时效性差异化
   - 有心理学依据支持差异化阈值
   - 但作为保守起点，统一阈值也可接受

5. **P4（观察后调整）**：权重比例 0.75:0.25
   - 无明确依据，但作为灰度起点合理
   - 应根据实际数据（点击率、匹配成功率）调整

### 8.1 AI 直接读取核心结构化测评画像

3. 候选人基础资料（如果没有测评）
4. 系统已有的保守排序结论

### 8.2 AI 的职责

AI 负责：

- 结合用户核心结构化测评画像判断候选人是否更适合
- 候选人没有测评时，基于资料判断适配性
- 解释为什么适合
- 提醒可能的磨合点

### 8.3 AI 的边界

AI 不负责：

- 伪造候选人的测评结果
- 把候选人强判成具体 MBTI 再绝对化下结论
- 把人格匹配说成固定公式

要求 AI 使用这种表达：

- “从你的 MBTI 和对方资料看，更可能适合……”
- “从关系节奏上看，冲突风险较低……”
- “如果你比较在意理解感，这个人的资料里有对应信号……”

不应使用这种表达：

- “INFP 一定最适合 XXX”
- “你们就是绝配”
- “这个人就是 ENFJ 型”
