# 语音输入功能测试清单

## 📱 基础功能测试

### 1. 麦克风权限测试
- [ ] 首次点击麦克风按钮，浏览器弹出权限请求
- [ ] 允许权限后，按钮变为可用状态
- [ ] 拒绝权限后，按钮显示禁用状态
- [ ] 在浏览器设置中手动禁用麦克风权限，按钮显示禁用状态

### 2. 录音功能测试
- [ ] 按住麦克风按钮，录音面板出现
- [ ] 录音面板显示音量波形动画（8个动态条）
- [ ] 录音面板显示录音时长（实时更新）
- [ ] 说话时音量波形跳动（音量>5）
- [ ] 不说话时音量波形不动（音量<5）
- [ ] 松开按钮后，录音面板立即消失

### 3. 上滑取消功能测试
- [ ] 录音时手指上滑超过80px，显示"松开取消"提示
- [ ] 上滑后松开，录音面板消失，不发送消息
- [ ] 上滑距离不足80px松开，正常发送消息

### 4. 音量提示测试
- [ ] 音量<5时，显示"⚠️ 未检测到声音，请检查麦克风"
- [ ] 音量<20时，显示"音量较低，请靠近麦克风"
- [ ] 音量正常时，显示"松开发送，上滑取消"

### 5. 发送流程测试
- [ ] 松开后，消息直接出现在聊天界面（无"识别中..."提示）
- [ ] 识别成功后，消息文本正确显示
- [ ] 识别失败后，显示简短提示"未识别到语音内容，请重试"

## 🎤 音频质量测试

### 10. 正常语音测试
- [ ] 清晰说话："你好，我正在测试语音功能"，识别正确
- [ ] 中文语音："今天天气很好"，识别正确
- [ ] 数字语音："123456"，识别正确
- [ ] 英文语音："Hello world"，识别正确（Whisper支持多语言）

### 11. 噪音环境测试
- [ ] 安静环境录音，识别成功
- [ ] 有背景音乐录音，仍能识别主要内容
- [ ] 有风声录音，仍能识别主要内容
- [ ] 有多人说话录音，Whisper识别主要声音

### 12. 幻觉检测测试
- [ ] 静音录音（不说话），识别结果为空或过滤掉幻觉内容
- [ ] 噪音录音（敲桌子、吹气），识别结果为空或过滤掉幻觉内容
- [ ] 识别结果包含"请不吝点赞订阅转发打赏"等YouTube结尾词，被正确过滤

## ✅ 微信体验一致性测试

### 19. 核心体验对比
- [ ] 按住→松开→发送流程流畅（无等待感）
- [ ] 松开后录音面板立即消失（微信式体验）
- [ ] 无"识别中..."等待状态提示（微信式隐藏技术细节）
- [ ] 消息发送后直接出现在聊天界面（无中间状态）
- [ ] 上滑取消功能流畅（与微信一致）

### 20. 用户感知测试
- [ ] 用户感觉是"实时发送"（非"录音→等待→发送")
- [ ] 用户不需要知道Whisper模型、下载等技术细节
- [ ] 用户只需要"按住说话→松开发送"
- [ ] 整个流程简洁直观，无学习成本
