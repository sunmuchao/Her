# 发现页重构任务拆分方案

> **基于诊断报告**：discovery-architecture-diagnosis-report.md  
> **核心原则**：AI 是决策大脑，代码是助手，提示词是规则手册  
> **重构目标**：让 AI 红娘从"复读机"变成"真人红娘"  

---

## 📋 总览

| Phase | 任务数 | 预估工作量 | 风险等级 | 验证方式 |
|-------|--------|-----------|---------|---------|
| Phase 1 | 4个任务 | 2-3天 | 低风险 | 手动测试对话 |
| Phase 2 | 5个任务 | 5-7天 | 中风险 | 回归测试 + 对话测试 |
| Phase 3 | 3个任务 | 2-3天 | 低风险 | 工具返回验证 |
| Phase 4 | 2个任务 | 1-2天 | 低风险 | AI 对话质量验证 |

**总预估工作量**：10-15天（建议分阶段实施，每阶段验证后再继续）

---

**验证标准**：手动测试对话，AI 能正确理解意图

## 🎓 核心原则总结

**一句话总结**：
> **AI 是决策大脑，代码是助手，提示词是规则手册。**

**记住这个公式**：
```
AI（老板）+ 代码（助手）+ 提示词（规则手册）= 智能系统

❌ 错误：代码（老板）+ AI（员工）+ 提示词（混乱规则）= 复读机
✅ 正确：AI（决策）+ 代码（执行）+ 提示词（软约束）= 真人红娘
```

**硬约束 vs 软约束分层**：
```
硬约束（代码执行）：
├─ 安全边界（封禁用户、黑名单）
├─ 数据校验（必填字段、格式）
├─ 权限校验（会话状态）
└─ 商业限制（付费、次数）

软约束（Prompt 表达）：
├─ 反馈调整策略
├─ 追问时机判断
├─ 输出风格个性化
└─ 业务规则（同城优先、年龄匹配）
```
